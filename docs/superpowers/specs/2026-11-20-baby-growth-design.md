# 宝宝成长曲线设计

## 依据与范围

参考视频接触图第 3 行第 4 格的测量表单字幕提到“会生成一个折线图”。现有 Web、微信小程序共用成长记录接口，但均未呈现测量曲线。本模块补齐这项参考功能；仅用已有 `/growth` 数据，不新增数据库字段或接口，不恢复原生 Android/iOS。

用户已授权自动决定并持续开发、不提问；设计与实现作为同一功能模块提交后立即推送。

## 选择

采用独立身高／体重切换的折线图：Web 使用 Vue-ECharts，uni 使用 uni-echarts，两者复用 ECharts 按需模块及一份共享数据投影。双 Y 轴容易把两种单位混淆；自绘图增加跨端生命周期维护，均不采用。沿用现有卡片、暖色和组件库，不改动其他页面。

uni 使用官方支持的手动 `provideEcharts` 与依赖预构建排除。自动插件在本仓根 Vue 3.5 编译器与 uni 嵌套 Vue 3.4 编译器混用时实际报 `shared.genCacheKey is not a function`；手动方案仅替代 H5／微信目标的注入与排除职责，不改变全局 Vue 版本。该组件 2.5.4 在延迟初始化和画布查询后缺少卸载检查，另以精确 SFC 的 Vite pre-transform 补齐失效、实例身份及 disposed 检查，保留 sourcemap；源码片段不匹配时构建失败，避免升级后静默漏补。

uni 在 `configResolved` 时会把条件编译器插到插件数组最前，单靠 `enforce: pre` 仍可能收到已删除 WEB 代码的源码。补丁使用 `transform: { order: 'pre', handler }`，先校验并修改原始完整 SFC，再由官方条件处理器生成 H5／微信版本；真实 Vite 排序和官方 uni 处理器回归覆盖 serve/build 两种配置。H5 开发预构建显式包含 ECharts 模块和 shared 子路径，避免首次进入宝宝页时动态优化触发整页重载；仍排除 uni-echarts，以保留原始 SFC 补丁入口。

微信实际构建又确认根目录提升的 npm 组件被 uni 归一为 `../../node-modules/...`，Rollup 拒绝相对输出文件名。沿用现有 Wot 同步方式，将锁定发布包的源码和许可复制到被忽略的 `src/uni_modules/uni-echarts`，不提交第三方生成源码。Vite 只为 `uni-echarts` 与 `uni-echarts/shared` 两个精确入口设置应用内别名，保证组件与注入函数使用同一份 shared-core；生命周期补丁只匹配对应发布组件与生成组件路径，并继续校验版本及八组锚点。实际构建核对 usingComponents、JS、WXML、WXSS 路径闭合，不通过改写输出文件名掩盖路径错误。

## 数据规则

- `projectGrowthMeasurements(records)` 输出 `{height, weight}`，每点 `{id, date, value}`。接受已有记录类型，独立读取测量字段，避免丢弃合法健康记录中的测量。
- 只纳入严格合法的 `YYYY-MM-DD` 与有限正数；身高上限 250 cm、体重上限 200 kg，匹配 API 合同。null、空串、字符串数字、NaN、Infinity、零、负数及越界数据不转换、不补零。
- 日期升序，同日按有效 createdAt 时间、再按 id 稳定排序；无效或缺失 createdAt 统一置于有效时间之前。保留同日所有有效记录，不平均、不按输入数组次序挑选。输入不变异。
- 两个指标独立过滤和取最近值，补录更早日期不会替换最近测量。仅填体重的新记录不会抹去最近身高。
- 图表使用分类日期轴，按测量记录依次等距排列；页面说明同日多次均保留。曲线取全部成长数据，不随列表类型或搜索筛选变化。

## 页面行为

卡片提供组件库的身高／体重切换，显示当前指标记录数、最近测量值与日期。空指标显示对应填写引导；单条数据画一个点并说明再添一条可连成曲线。已有多点用折线连接，不显示医学正常范围或评价。图表固定适当高度、宽度随容器调整，清楚标注日期及单位；tooltip 仅使用受控日期和数值，避免插入记录中的任意 HTML。Web 和 H5 测试检查真实图实例数据及手机宽度。微信编译通过与微信运行验收分别报告。

## 验收边界

先以共享纯函数、真实组件与页面回归复现缺失行为，再实现。浏览器使用隔离的临时数据库，验证缺失／单点／同日／乱序日期、指标切换、创建编辑删除刷新、列表筛选独立、窄屏与卸载重进。完整单测、类型检查、Web/mp-weixin/H5 构建及完整两套浏览器验收后提交推送。检查微信包体变化。生产 3003 仅只读验证；5174 不动；不重试已被策略拒绝的旧目录清理，也不把 H5 成功当成微信运行通过。
