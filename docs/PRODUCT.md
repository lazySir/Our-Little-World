# 我们的小世界 — 产品设计

## 目标与依据

为一对伴侣提供可部署在个人电脑、NAS 或小主机上的完整私人生活空间。参考用户提供的 158 秒视频，采用温暖的奶油色、手账卡片和粉彩插画视觉。所有主要操作必须真实持久化；不以静态演示数据代替功能。两个入口是支持桌面和手机响应式布局的 Web，以及微信小程序。

用户已明确要求自动完成、不提问；具体设计、依赖和实施选择由开发方自主决定。每完成一个功能模块独立提交，提交格式为 emoji + conventional type + 中文描述。

## 产品范围

1. 首次创建空间、账号登录、邀请码加入、双人上限、修改密码、登出与会话失效。
2. 首页：在一起天数、今日心情、下个纪念日、待办愿望、最近回忆、当月账本和模块入口。
3. 一起做：愿望 CRUD、分类、搜索、完成/重开、目标日期。
4. 今天吃什么：菜品/饮品/餐厅 CRUD、收藏、搜索、购物篮与双人点单、完成订单。
5. 共同账本：收支 CRUD、金额分为单位、日期/月筛选、付款人、分类统计与趋势。
6. 纪念日：自定义日期、每年重复、倒数/已过天数、闰日处理。
7. 回忆相册：文字、多图、日期、标签、预览与删除，愿望完成可转为回忆。
8. 宝宝成长：可选的宝宝档案、身高体重曲线、喂养、睡眠、健康备注与里程碑；成长记录中的照片自动汇集为宝宝相册，按记录日期倒序、按附件 ID 去重，保留标题与日期并支持预览；曲线独立切换指标、保留同日多次测量，仅提供家庭记录。
9. 工作手记：带日期、标签和图片的工作记录，搜索与编辑删除。
10. 时光信箱：写信、设置未来解锁日，未到期内容由服务端隐藏。
11. 设置：两人昵称、空间名、在一起日期、主题、邀请、接口地址、密码、数据导出和备份恢复。
12. 共享日历：按月查看纪念日、愿望目标日、时光信解锁日、回忆、成长记录、历史心情和宝宝生日；心情事件显示作者、心情值和备注，可按类型筛选。支持来源的单日事件可打开对应记录；每年重复日期按年展开，非闰年把 2 月 29 日映射到 2 月 28 日，仍可打开原纪念日或宝宝档案；来源已删除时保留来源提示并提供返回全部，不会误显示建档或普通成长列表。未解锁信件只显示锁定状态，不暴露正文。

## 体验约束

- Web 桌面使用侧栏，手机使用底部主导航，常用入口不超过五个；次级功能经首页/更多进入。
- 共享日历在 Web 和 uni-app 页面保持一致的月份、事件类型与单日详情；按服务端日期标识今天。
- Web 与微信小程序以服务端 `TZ` 业务日期（默认 `Asia/Shanghai`）作为日期默认值和月份基准，避免不同设备时区造成跨午夜偏差。
- Web 使用 Element Plus；uni-app 使用 Wot Design Uni；表单、确认、通知、空状态优先使用组件库。
- 每次保存有进行中状态、成功提示和明确错误；删除需要确认；空空间提供引导。
- Web 筛选组向辅助技术报告选中状态，照片选择支持键盘焦点操作；窄高桌面导航可滚动，断网提示不覆盖页面内容。
- 小程序首次读取失败时提示重试，成功读取后才显示空状态和统计；刷新失败仍保留最后读到的内容；切换月份失败时回到最后成功月份，避免把旧事件显示在新月份格子中。
- 默认数据为空，通过显式 demo 命令建立独立演示空间；不提交口令、用户图片或数据库。
- 完整 ZIP 备份包含 SQLite 与服务内图片；上传图片经尺寸限制和 WebP 转换，相机原片另行保存。默认每 24 小时自动备份，保留最新 7 份自动备份；恢复先验证格式并自动备份旧数据。
- 不包含即时聊天、实时定位、公开社区、AI 或第三方付费服务。

## 架构

Npm workspaces，业务源码统一 TypeScript：apps/web（Vue 3/Vite/Element Plus/Tailwind/Pinia/Router/ECharts），apps/uni（Vue 3/uni-app/Vite/Wot Design Uni/Tailwind + weapp-tailwindcss），apps/api（NestJS 11/TypeScript/Prisma 7/SQLite，使用 `@prisma/adapter-better-sqlite3` 驱动），packages/shared（日期、金额、类别常量）。部署脚本采用 TypeScript `.mts`，Windows 入口采用 PowerShell。

Web 支持电脑和手机浏览器，也可在浏览器支持时添加到主屏幕；PWA 提供独立窗口和离线页面外壳，但不缓存私人记录、会话或图片。uni-app 输出微信小程序，并保留 H5 构建用于浏览器联调。两端使用相同的业务接口和持久化数据。

NestJS 提供统一 /api。数据库及附件只由服务端访问；每项资源均限定当前空间。密码哈希、随机会话、限流、参数校验、上传类型/大小校验、附件签名访问、授权备份。SQLite 使用 WAL，Prisma 管理版本迁移。

## 部署与发布边界

默认本地 0.0.0.0:3000，Nest 托管 Web 生产构建，同一地址覆盖电脑和手机浏览器。提供 Windows 启动脚本、Docker Compose、环境样例、备份恢复和外网 HTTPS 指引。微信发布需用户自己的 AppID、主体与域名配置，交付可编译源代码与开发者工具导入产物。公网部署与微信正式发布按用户明确授权执行。

## 验收

真实数据库 API 集成测试涵盖账号、双人配对、访问控制、各模块 CRUD、共享日历聚合与未来信件隐藏、上传和备份。共享日期/金额逻辑单元测试。Web 浏览器端完成首次创建、核心模块操作、刷新持久化、手机响应式布局。Web 与微信小程序分别构建，H5 用于小程序页面联调；产品交付前检查 Git 提交、干净工作区和完整启动文档。
