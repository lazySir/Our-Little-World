## 本轮已修复的问题

- Web 弱网下的成功认证、资料补全失败、真实会话过期和离线退出不再互相混淆。
- 两端列表忽略过期请求；小程序首页不再让页面刷新或保存前的旧请求覆盖保存失败后的草稿。
- 两端心情保存锁住输入和重复提交，失败后恢复操作并保留草稿。小程序写信默认日期不再缓存到次日。
- 微信编辑请求改为 POST 携带受限 PATCH 覆盖头，并保留认证与写入锁。
- 小程序组件库图标改用随依赖分发的字体，修复离线或字体 CDN 不通时密码栏出现方框的问题。
- 两端连接新服务前匿名探测，拒绝无关 JSON；旧检查结果、旧会话响应和旧401不再覆盖新连接；连接和账号/设置操作互斥。
- 首页的日期、心情、当月统计和纪念日共用一次服务端日期；写入心情由服务端确定当天，跨午夜保留昨天记录并清理旧输入。
- Web 记账防重复保存，保存期间锁住关闭、取消和字段，失败保留草稿。两端点单保存期间锁住购物篮与备注，失败可重试；uni 公共编辑器统一保护文字、数字、日期、选择项和开关。
- 小程序备份直接分享下载得到的临时文件，避免每次导出累积永久缓存；取消分享不再报错或提示已保存，失败与旧微信版本提供明确指引。平台适配回归覆盖微信编译分支，文件分享仍需真机验收。
- uni 上传照片期间阻止提前保存和关闭，上传失败后恢复操作。
- Web 回忆、手记、菜单、成长和宝宝头像上传期间禁用取消、关闭按钮、遮罩和 ESC；保存期间锁定表单和照片操作，回车提交也遵守上传锁，失败后释放操作。
- uni ZIP 恢复成功后保持登录，刷新空间并返回首页。

- 局部更新订单不再用默认值覆盖未提交的备注或状态。
- 当前照片丢失时仍可恢复以前的完整备份；保护副本标记缺失项，正常备份明确报错。
