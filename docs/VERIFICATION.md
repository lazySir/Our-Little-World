## 本轮已修复的问题

- 微信编辑请求改为 POST 携带受限 PATCH 覆盖头，并保留认证与写入锁。
- 小程序备份直接分享下载得到的临时文件，避免每次导出累积永久缓存；取消分享不再报错或提示已保存，失败与旧微信版本提供明确指引。平台适配回归覆盖微信编译分支，文件分享仍需真机验收。
- uni 上传照片期间阻止提前保存和关闭，上传失败后恢复操作。
- Web 回忆、手记、菜单、成长和宝宝头像上传期间禁用取消、关闭按钮、遮罩和 ESC；保存期间锁定表单和照片操作，回车提交也遵守上传锁，失败后释放操作。
- uni ZIP 恢复成功后保持登录，刷新空间并返回首页。
- Web 可展开全部点单，较早订单可以完成和删除。
- 局部更新订单不再用默认值覆盖未提交的备注或状态。
- 当前照片丢失时仍可恢复以前的完整备份；保护副本标记缺失项，正常备份明确报错。
- 资源列表不再静默截断为1000条，首页月份合计包含完整历史。
- 照片列表不再截断为1000条，旧宝宝头像仍能在编辑时显示和移除。
- 备份生成与恢复统一限制为10000条生活记录、10000个 ZIP 成员（含3个固定文件）、每图10MiB、展开250MiB和压缩100MiB。超限明确拒绝并提供停机离线备份指引，自动备份失败保留旧档；缺失或大小异常照片仍可通过完整旧备份修复。
- 浏览器测试由自身生命周期清理临时服务与数据，Windows退出也经过验证。

## 验证边界

微信小程序源码与产物可以编译；H5覆盖共享页面逻辑，不能代替微信真机。真实 AppID、合法请求/上传/下载域名、相机相册权限、图片预览、文件分享和ZIP恢复仍需微信环境验收。Docker 镜像与 Compose 已通过上述本机隔离验收。

没有创建日常账号、写入真实生活记录、开启外网发布或提交私密数据库与图片。默认启动进入空空间的首次创建页。

## 平台清理

当前 `apps` 只有 `api`、`web`、`uni`；uni 构建目标只有 `h5` 和 `mp-weixin`。原生应用源码、Capacitor 配置、APK 与相关本地 SDK/JDK/Gradle 生成物已在前序提交清理。必需的第三方编译依赖可能含跨平台内部实现，不作为本产品的原生交付目标。
